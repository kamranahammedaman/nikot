# ESP32-S3 ক্লাউড পস থার্মাল প্রিন্টার সেটআপ গাইড (WiFi & Cloud Dynamic Printing)

আপনার ESP32-S3 ডিভাইসটি ওয়াইফাই কানেক্টেড রেখে সরাসরি ক্লাউড থেকে ফার্মেসী বিল রিসিট প্রিন্ট করতে পারবে। এই সিস্টেমে কোনো আইপি বা ক্যাবলের বাধ্যবাধকতা নেই; বিশ্বের যেকোনো প্রান্ত থেকে অ্যান্ড্রোয়েড অ্যাপে সেল সাবমিট করলেই প্রিন্টারটি স্বয়ংক্রিয়ভাবে রিসিট প্রিন্ট করে বের করবে।

নিচে এটি কীভাবে কাজ করে এবং কীভাবে সেটআপ করবেন তা সহজ ভাষায় ধাপে ধাপে বুঝিয়ে দেওয়া হলো:

---

## ১. ESP32-S3 প্রিন্টারের মালিকানা যেভাবে সনাক্ত হবে (Authentication)
আমরা অ্যাপ এবং ESP32 এর জন্য একটি **Dynamic Ownership Model** ব্যবহার করেছি:
- **অনন্য মালিকানা কী (Unique Owner ID):** আপনি যখন অ্যান্ড্রয়েড অ্যাপে লগইন করবেন, তখন প্রতিটি ফার্মেসী অনারের একটি ইউনিক ইউজারনেম থাকে (যেমন `admin_username` বা `pharmacy_a`)।
- **ক্লাউড কিউ (Cloud Print Queue):** অ্যাপে যখনই কোনো বিল তৈরি বা রিটার্ন করা হয়, সেটি সরাসরি Firebase Realtime Database এর `print_jobs/<ownerUsername>/<job_id>` নোডে যুক্ত হয়।
- **ডিভাইস ফিল্টারিং:** আপনার ESP32-S3 শুধুমাত্র তার জন্য নির্ধারিত `ownerUsername` নোডের কিউ (Queue) মনিটর করবে। ফলে একের অধিক এডমিন বা বিভিন্ন ফার্মেসীর জন্য আলাদা আলাদা প্রিন্টার কোনো ঝামেলা ছাড়াই একসাথে স্বয়ংক্রিয়ভাবে কাজ করতে পারবে!

---

## ২. ডাইনামিক ওয়াইফাই ও মালিকানা পরিবর্তন (WiFiManager & Config Portal)
প্রিন্টারের মালিকানা বা ওয়াইফাই নেটওয়ার্ক যেকোনো সময় পরিবর্তন করার জন্য আমরা **WiFiManager** লাইব্রেরি ব্যবহার করেছি। এর ফলে কোড পরিবর্তন না করেই আপনি প্রিন্টারটি যেকোনো ফার্মেসীতে নিয়ে ইনস্ট্যান্ট সেটআপ করতে পারবেন:

1. **প্রথমবার চালু বা নতুন সেটিংস:**
   - ডিভাইসটি অন করার পর যদি এটি আগের কোনো ওয়াইফাই খুঁজে না পায়, তবে এটি নিজেই একটি লোকাল ওয়াইফাই হটস্পট (Access Point) তৈরি করবে। যার নাম হবে: **`PharmaPrinter-Setup`**।
   - আপনি আপনার মোবাইল বা ল্যাপটপ দিয়ে এই ওয়াইফাই নেটওয়ার্কে কানেক্ট হবেন।
   - কানেক্ট হওয়ার সাথে সাথে মোবাইলে একটি কনফিগারেশন পেজ (Captive Portal) চলে আসবে। যদি না আসে, তবে যেকোনো ব্রাউজারে গিয়ে `192.168.4.1` লিখে এন্টার দিন।

2. **কনফিগারেশন পেজে যা পূরণ করতে হবে:**
   - **WiFi SSID & Password:** যে ওয়াইফাইয়ের সাথে ডিভাইসটি কানেক্ট করতে চান তা সিলেক্ট করে পাসওয়ার্ড দিন।
   - **Pharmacy Owner Username:** এই প্রিন্টারটি যে ফার্মেসী বা এডমিনের বিল প্রিন্ট করবে তার অ্যাপ ইউজারনেমটি লিখুন (যেমন: `admin_username`)।
   - **Printer Security Key:** সিকিউরিটি নিশ্চিত করার জন্য একটি পিন বা কোড।
   - **Firebase URL:** আপনার ফায়ারবেস ডেটাবেজ লিংকটি লিখুন।
   - এরপর **"Save"** বাটনে চাপ দিন। 
   
3. **চিরস্থায়ী মেমোরি সংরক্ষণ (Preferences/NVS):** 
   - সেভ করার পর ESP32-S3 এই তথ্যগুলো তার মেমরিতে (Non-Volatile Storage) চিরদিনের জন্য সেভ করে রাখবে এবং লোকাল ওয়াইফাইয়ের মাধ্যমে ইন্টারনেটে কানেক্ট হবে।
   - **মালিকানা পরিবর্তন করতে চাইলে:** ESP32-S3 বোর্ডের **BOOT** বাটনটি চেপে ধরে ডিভাইসটি রি-স্টার্ট (RESET) করলেই মেমোরি ক্লিয়ার হয়ে আবার নতুন করে কনফিগারেশন পোর্টাল ওপেন হবে। এর ফলে যেকোনো সময় মালিকানা পরিবর্তন করা যাবে!

## ৩. হার্ডওয়্যার কানেকশন ও ওয়্যারিং (Hardware Wiring Guide)
আপনার পাঠানো ছবি অনুযায়ী, ESP32-S3 এর **USB OTG পোর্ট** ব্যবহার করে খুব সহজে সরাসরি থার্মাল প্রিন্টারে ডেটা পাঠানো সম্ভব:

```
+------------------+                   +----------------------+
|                  |     USB-C to A    |                      |
|    ESP32-S3      |     OTG Adapter   |  USB POS Printer     |
|  [USB OTG Port]  |==================>| (Thermal/Receipt)    |
|                  |                   |                      |
+------------------+                   +----------------------+
         |                                         |
    5V Power Input                            Power Cable
   (From USB UART or                         (Wall Adapter)
    External 5V Pin)
```

- **ESP32-S3 USB OTG পোর্ট:** বোর্ডের দুটি ইউএসবি পোর্টের মধ্যে একটি হলো UART (কোড আপলোড করার জন্য) এবং অন্যটি হলো Native USB/OTG। আপনাকে পিন্টারের কানেকশনটি অবশ্যই **USB-C OTG** বাটন বা পোর্টে দিতে হবে।
- **পাওয়ার সোর্স:** পোর্টেবল বা নিরবচ্ছিন্ন ব্যবহারের জন্য ESP32-S3 বোর্ডটিকে একটি ভালো মানের 5V USB চার্জার বা পাওয়ার এডাপ্টার দিয়ে পাওয়ার দিন।

## ৪. বিল যেভাবে স্বয়ংক্রিয়ভাবে প্রিন্ট হবে (Execution Flow)
আপনার অ্যান্ড্রয়েড ফার্মেসী অ্যাপ এবং প্রিন্টারের লাইভ মেলবন্ধন যেভাবে কাজ করবে:

1. **অ্যাপে সেল কনফার্মেশন:** আপনি বা আপনার স্টাফ যখনই অ্যাপে বিল কনফার্ম করবেন (অথবা বিল হিস্ট্রি থেকে "প্রিন্ট" বাটনে ক্লিক করবেন), অ্যাপ সরাসরি ফায়ারবেসের নির্দিষ্ট অনার নোডে প্রিন্ট জব পাঠিয়ে দিবে: `/print_jobs/<ownerUsername>/<job_id>`.
2. **ESP32-S3 পোলিং:** ইন্টারনেট কানেক্টেড থাকা অবস্থায় ESP32-S3 প্রতি ৪ সেকেন্ড পর পর ব্যাকগ্রাউন্ডে চেক করবে তার নোডে কোনো `status: "pending"` নামের বিল আছে কিনা।
3. **রিসিট ফরম্যাটিং ও প্রিন্ট:** পেন্ডিং বিল পাওয়ামাত্রই ESP32-S3 ডেটাবেজ থেকে বিল নম্বর, আইটেমের নাম, কোয়ান্টিটি, ডিসকাউন্ট, অপারেটর এবং মোট বিলের হিসাবটি ডাউনলোড করবে এবং ESC/POS কমান্ডে রূপান্তর করে USB দিয়ে প্রিন্টারে পাঠিয়ে দিবে।
4. **অটো-কাট ও কিউ ক্লিয়ার:** রিসিটটি প্রিন্ট হয়ে বের হয়ে যাওয়ার পর ESP32-S3 ফায়ারবেসে ওই বিলের স্ট্যাটাস পরিবর্তন করে `"printed"` করে দিবে, যাতে একই বিল বারবার প্রিন্ট না হয়।

## ৫. Arduino IDE-তে যেভাবে বিল্ড ও আপলোড করবেন
১. আপনার কম্পিউটারে **Arduino IDE** ওপেন করুন।
২. **Preferences**-এ গিয়ে ESP32 Board URL যুক্ত করুন এবং **ESP32 by Expressif Systems** (সংস্করণ ৩.০+) বোর্ড ম্যানেজার থেকে ইন্সটল করুন।
৩. Board হিসেবে **"ESP32S3 Dev Module"** সিলেক্ট করুন। 
৪. **USB CDC On Boot** অপশনটি `Enabled` রাখুন।
৫. Library Manager থেকে **WiFiManager** এবং **ArduinoJson** লাইব্রেরি দুটি ইন্সটল করে নিন।
৬. আপনার এই প্রজেক্টের `/esp32_printer/PharmaPrinter.ino` কোডটি কপি করে পেস্ট করুন এবং আপলোড দিন।
